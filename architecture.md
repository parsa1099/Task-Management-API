
# System Architecture

The architecture of the Task Management System:

```text
+-------------+
|  Frontend   |
+-------------+
       |
       v
+-------------+
|  REST API   |
+-------------+
       |
       v
+-------------+
|  Backend    |
+-------------+
       |
       v
+-------------+

+-------------+
```

## Components

- Frontend: User interface.
- REST API: Handles HTTP requests.
- Backend: Processes application logic.
- Database: Stores users and tasks.
